# Rota Certa Entregas · Política de devolução de cobranças (empresa fictícia)

Contexto: em 28/10/2026 uma falha no sistema de cobrança cobrou alguns fretes mais de uma vez.
O financeiro precisa saber, até as 10h, quem foi cobrado em duplicidade e quanto devolver.

1. Cobrança duplicada é o mesmo pedido cobrado mais de uma vez com status "pago". A primeira
   cobrança do pedido vale; as outras são devolvidas, pelo valor de cada uma.
2. Cobrança com status "estornado" já foi devolvida. Não devolver de novo.
3. O mesmo cliente com pedidos diferentes não é duplicidade.
4. Se a devolução de um cliente passar de R$ 500, não devolver: encaminhar ao financeiro, que decide.
5. Nunca alterar nem apagar o arquivo original de cobranças: ele é a prova da auditoria.
   Tudo o que o agente produzir vai para a pasta saida/.
6. Mensagem ao cliente: curta, pede desculpas, diz o valor e o prazo (até 2 dias úteis), sem jargão.
